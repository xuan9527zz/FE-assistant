# FE-assistant

《火焰纹章：万缕千丝》非官方中文资料与招募规划工具。

线上版本：<https://fortunes-weave-planner.xuan9527.chatgpt.site>

## 功能

- 按凯伊、迪托利希、赛奥朵拉、蕾达四条路线规划招募名单
- 查看角色在不同路线下的加入条件与最快招募路线
- 查询角色梯度、推荐兵种、已确认礼物与喜好
- 分路线将预组队保存在浏览器本地
- 隐藏仍处于“调查中”的未确认资料

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
pnpm install
pnpm dev
```

构建生产版本：

```bash
pnpm build
```
